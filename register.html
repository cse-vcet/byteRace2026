Project Submission Instructions

  1. Create a Google Drive folder named teamname_TeamLeadUsn (e.g., lumos_4vpxx0xx or lumos_1fy****).
  2. Set the folder access to Anyone with the link.
  3. Upload the mandatory project presentation in PDF format only. If your presentation is in PPT, PPTX, ODP, or any other format, export or convert it to PDF before uploading.
  4. If you have a working hardware prototype, you may upload a short demonstration video to the same folder. The demonstration video is optional.
  5. Submit the Google Drive folder link in the field below.
